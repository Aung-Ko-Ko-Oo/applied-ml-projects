# 🤖 Intellectual Tutor: Deep Learning-Based Document Sentiment & Summary Analyzer

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![Framework](https://img.shields.io/badge/Framework-PyTorch%20%7C%20HuggingFace-orange.svg)](https://huggingface.co/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An end-to-end NLP pipeline that transitions from a **Beginner-level Machine Learning** approach to an **Advanced-level Deep Learning** solution. This system automatically classifies the sentiment of a document and generates abstractive summaries using Transformers.

---

## 🗺️ Project Roadmap (Beginner to Advanced)

| Level | Component | Technology Used | Description |
| :--- | :--- | :--- | :--- |
| **Beginner** | Preprocessing & Tokenization | `NLTK` | Cleaning text, removing stopwords, and tokenizing input data. |
| **Intermediate** | Text Classification | `Scikit-Learn` (TF-IDF + Logistic Regression) | Training a baseline ML model to predict document sentiment. |
| **Advanced** | Abstractive Summarization | `Hugging Face` (`BART` Transformer Model) | Utilizing state-of-the-art Deep Learning to generate readable text summaries. |
