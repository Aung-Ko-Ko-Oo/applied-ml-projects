# 🏡 End-to-End Housing Market Predictor Pipeline

A modular machine learning project designed to process raw feature vectors and predict market value transformations using an end-to-end regression engine.

## 📊 Pipeline Architecture
The project is built entirely on production-style decoupled files instead of static notebook scripts:
* **`src/data_processor.py`**: Isolates pipeline transformations, handles scaling transformations, and splits arrays.
* **`src/model.py`**: Controls model wrappers, hyperparameter evaluations, and scoring metrics.
* **`train.py`**: Main application engine to trigger the full process.
